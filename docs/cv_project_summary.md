# CV Project Summary

## Project Name

SD Travel Guide

## One-line Version

Built a Flutter-based Sri Lanka tourism app with AI travel assistance, itinerary planning, translation, smart maps, safety tools, and budget tracking.

## Resume Bullet Ideas

- Developed a mobile tourism app in Flutter focused on Sri Lanka travel, combining itinerary planning, translation, destination discovery, and safety workflows.
- Built a local-first AI travel assistant that answers Sri Lanka-specific travel questions and supports practical trip-planning prompts.
- Designed and implemented a dynamic itinerary builder with editable destination flows, traveler mood personalization, and budget-aware guidance.
- Integrated map, place, wallet, offline-survival, and profile modules into a single travel app experience with a custom dark premium UI.
- Added backend and admin foundations for authentication, OTP, profile data, analytics, and dashboard-driven app management.

## Interview Description

This project was built as a travel super app concept for Sri Lanka. The goal was to move beyond a simple information app and create a decision-support app that helps tourists plan, navigate, translate, budget, and stay safe in one place.
