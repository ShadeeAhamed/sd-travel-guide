# Connect This Project to GitHub

## 1. Create a new empty repository on GitHub

Suggested name:

- `sd-travel-guide`

Do not add a README, license, or `.gitignore` on GitHub when creating it.

## 2. Run the helper script from this project

```powershell
cd C:\Users\U S E R\tourist_guide
.\tool\connect_github.ps1 -RepoUrl https://github.com/YOUR_USERNAME/sd-travel-guide.git
```

## 3. Add it to your CV

Use the GitHub repository link plus a short project description such as:

`SD Travel Guide - Flutter tourism app for Sri Lanka with itinerary planning, maps, translation, safety tools, and AI travel assistance.`
